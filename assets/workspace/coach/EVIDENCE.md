# 证据分级与引用规则（Evidence）

> 目的只有一个：让每一句分析都能回答"依据是哪一级证据"，而不是"听起来很专业"。
> 分析输出前先过一遍本文件。做不到分级的结论，宁可不写。

## 1. 五级证据

| 等级 | 名称 | 含义 | 能否单独支撑决策 |
|---|---|---|---|
| E1 | 原文可定位 | 精确到页码/表号/章节，且**实际核对过** | 可以（限该来源覆盖范围） |
| E2 | 领域共识 | 教科书级、多来源一致的基础概念 | 可以（限概念层面，不可导出个体处方） |
| E3 | 个体实测 | 设备记录（附 ID）、正式成绩、用户明确确认的事实 | 可以（限该次测量范围） |
| E4 | 分析推断 | 由 E1–E3 推导，须写明前提与推断链 | **不可以**，只能作方向或假设 |
| E5 | 待核实 | 来源未核对、有冲突、采集异常 | **不可以**，不得进入课表 |

**升降级**：E4 只有获得新的 E3 实测验证才可升为 E3；不得因为"看起来合理"或"说过多次"升级。E2 套到具体个人身上，那一步是 E4。

**设备派生值**（设备估算的最大摄氧量、训练状态、负荷比、恢复时间、训练效果）一律记为 **E3-设备**，不是测量值，不得当作 E2 共识。

## 2. 引用格式

正文里用行内标记，等级必须跟在引用后面：

```
轻松跑配速应受心率与对话感约束 [BLUEPRINT §2 · E1]
本周三次轻松跑的配速—心率关系基本稳定 [10-23~10-28 · E3]
阈值能力是当前短板 [DECISIONS 2026-10-30 · E4]
```

只写来源不写等级，视为格式不合规。

## 3. 六类禁引（最常出现的幻觉形式）

1. **没核对过的页码或表号。** 没打开那一页，不许写"见 p123"。
2. **无出处的精确数字。** "某项研究显示提升 4.2%"——除非能给出可核查文献，否则禁止。这类句子是幻觉最常见的伪装。
3. **把共识写成个体处方。** "阈值训练应占周跑量 10%"是方向；"你应该跑 3 公里阈值"是个体决策，必须走 E4 → E3 验证。
4. **把推断写成结论。** 推断要保留"若……则……"结构，不得改成陈述句。
5. **用单次数据修改长期判断。** 一次好跑或一次跑崩只进入当日判读，不动能力锚点。
6. **跨设备、跨环境、跨装备链直接比较。** 见 `BLUEPRINT.md` §6。

## 4. 三条通用红线

- 不把设备估算值当作生理测量值。
- 能力评估调高，不等于负荷上限放宽。
- 不确定就写"无法判定"，不要为了完整性编一个答案。
