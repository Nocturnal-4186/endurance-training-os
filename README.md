# Endurance Training OS

给**只会跑步、不懂电脑**的人用的一套 AI 训练助手。

不需要会命令行、不需要懂 Python、不需要配 API。你把仓库地址发给任意一个能读写文件的 AI 编程助手（Codex / Claude Code / Cursor / WorkBuddy…），说一句"帮我装这个"，剩下的它会一步步问你。

---

## 它解决什么问题

AI 做训练不靠谱，通常不是模型不行，是三件事没做：

1. **没记忆** —— 每次开新对话它都是全新的，你上一周说过的话它不记得。
2. **爱编** —— 它不缺理由不说，除非你要求每句话挂来源。
3. **分不清假差异** —— 换表、换鞋、换季、GPS 漂移，它会把不可比的数据拿来做趋势分析。

这套东西给 AI 装上：**一个不会衰减的外部记忆、一套能追问来源的标准、一份写死了的规则**。

---

## 装好之后你得到什么

一个文件夹，里面有：

| 文件 | 作用 |
|---|---|
| `coach/ATHLETE_PROFILE.md` | 你是谁：目标、时间、设备、伤病限制 |
| `coach/BLUEPRINT.md` | **训练蓝本**：强度定义、能力锚点、阶段准入条件、负荷上限、数据口径 |
| `coach/EVIDENCE.md` | **证据分级**：E1–E5，以及六类禁止引用的说法 |
| `coach/TRAINING_LOG.md` | 训练记录：完成度、体感、疼痛、睡眠 |
| `coach/DECISIONS.md` | 每次训练决策和修订原因 |
| `coach/DATA_AUDIT.md` | 每次查数据的记录：查了什么、什么时候、成功没有 |
| `coach/LIBRARY_INDEX.md` | 你自己的资料（书、视频、笔记） |

另外还有：`.training_os/` 里放记忆引擎和 hooks，`data/garmin/raw/` 放原始数据（只追加，不修改）。

**蓝本是规格，其余是事实。** 两者冲突时事实优先，然后回头改蓝本 —— 不是拿规则去否定已经发生的事。

## 怎么装

### 第 1 步：选一个 AI 工具

支持这些（选你已有的就行）：

- **Codex**（OpenAI）
- **Claude Code**
- **Cursor**
- **WorkBuddy**
- **Gemini CLI**
- 其他能读写本地文件的 AI 助手（通用模式）

### 第 2 步：把地址给它

在对话框里粘这句话：

```
帮我装这个训练助手：<本仓库地址>
用对话式安装，一步一步问我，不要一次全问完。
```

它会先问你一个最简单的问题（比如"装到哪个文件夹"），你答完再问下一个。**全程不需要你打开命令行。**

### 第 3 步：填两个文件

装完它会让你填：

- `ATHLETE_PROFILE.md` —— 你的目标、每周能练几天、有什么老伤
- `BLUEPRINT.md` —— 可以先只填目标、时段和硬约束，强度和配速等你有比赛成绩再补

**不要让它替你编锚点数值。** 空白比编造的数字安全。

## 环境要求

- Windows / macOS / Linux
- Python 3.10+（3.11 / 3.12 更好），**不需要 pip install**
- 想接 Garmin 数据的话，需要一个 Garmin MCP 服务 + 一次本机登录

没有 Garmin 也能用 —— 手动把成绩和体感记进 `TRAINING_LOG.md` 就行。

---

## 隐私

- 所有数据留在你本机，**不上传任何服务器**
- 不读取、不保存你的 API Key、Cookie、OAuth token、密码
- Garmin token 由你本机的登录工具管理
- 仓库里不含任何人的训练数据、成绩、伤病记录

---

## 三条使用规则

装完之后，每次跟 AI 说话，开头加这一句：

```
先读 AGENT_GUIDE、BLUEPRINT、TRAINING_LOG、DATA_AUDIT。
告诉我：数据到哪天了？有新记录吗？有没有和以前冲突的？
然后再说我的问题。
```

再加三条：

1. **每个结论追问依据** —— "这个配速区间哪来的？"
2. **一次只让它改一个变量** —— 它很乐意同时给你改跑量、改强度、改动作，那是灾难配方
3. **拒绝"一次定三个月"** —— 让它按 2–4 周一个块给，每块结束复盘再进下一块

## 证据分级简表

| 等级 | 含义 | 能否单独支撑决策 |
|---|---|---|
| E1 | 原文可定位（有页码/章节） | 可以 |
| E2 | 领域共识（教科书级） | 可以，但不导出个体处方 |
| E3 | 个体实测（设备记录、正式成绩） | 可以 |
| E4 | 分析推断 | **不可以**，只能作方向 |
| E5 | 待核实 | **不可以**，不得进课表 |

设备算出来的最大摄氧量、训练状态、负荷比，一律算 `E3-设备`，不是生理测量。

## 卸载

删掉目标文件夹里的 `coach/`、`.training_os/`、`data/`，以及 `AGENTS.md` 里带 `training-os` 标记的那一段就行。

安装器不碰你原有的 `AGENTS.md`、`CLAUDE.md`、MCP 配置，只做带标记的增量合并。
