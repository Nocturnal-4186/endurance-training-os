## 6. 数据口径（通用，建议保留）

| 类别 | 规则 |
|---|---|
| 成绩 | 正式比赛/标准距离计时为唯一权威；设备时长与 GPS 距离只作核对 |
| 设备 | 跨设备不比较配速或心率；更换设备前后的数据不得直接连成趋势 |
| 环境 | 明显温差条件下不比较配速或心率；评估比赛先查当日天气 |
| 装备 | 不同鞋款/装备链分开统计，不混比 |
| 多来源 | 同一活动多平台并存时按活动 ID 匹配；证据不足保留两条并标"疑似重复"，不合并、不重复计跑量 |
| 可比性三问 | 同设备？同环境？同装备？任一为否 → 不做定量比较 |
| 设备派生指标 | 设备给出的最大摄氧量、训练状态、负荷比、恢复时间等均为**估算值**，不得单独构成训练决策依据 |

## 7. 禁止清单

1. 不在比赛或测试日引入未验证的变量（新跑姿、新装备、新配速策略）。
2. 不用"受主观控制的指标"当因果证据（主动压速度时的配速、刻意控制的心率上限）。
3. 不因单次数据修改长期判断；短期状态必须带日期。
4. 不做跨设备、跨环境、跨装备链的定量比较。
5. 不在无实测时给精确数值；不确定就写"无法判定"。
6. 不用目标成绩反推当前训练配速。
